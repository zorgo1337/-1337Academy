## 📖 О проекте

**1337Academy** — это многофункциональная сборка инструментов для студентов и школьников, которая автоматизирует рутинные учебные задачи: от генерации кода и блок-схем до оформления документов по ГОСТ и создания презентаций. В программу также встроен чат с современными нейросетями.

---

## ✨ Возможности

### 📊 1. Генератор кода и блок-схем

Автоматическое создание программ на C# и визуальных блок-схем по текстовому описанию заданий.

**Поддерживаемые типы задач:**
- 🔢 Математические вычисления (корни, степени, расстояния)
- 🔁 Работа с числами (чётность, сравнение, округление)
- 📐 Геометрические расчёты (площади фигур)
- 📈 Тригонометрические функции (синус, косинус)
- ✅ Логические проверки (положительное/отрицательное)

**Форматы вывода:**
- 📄 Word-документы с кодом
- 🖼️ SVG блок-схемы
- 🔄 Автоматическое открытие в Microsoft Visio

---

### 📄 2. Оформление документов по ГОСТ

Автоматическое форматирование документов Microsoft Word согласно российским государственным стандартам.

**Что настраивается:**

| Параметр | Значение |
|----------|----------|
| Шрифт | Times New Roman, 14 pt |
| Поля | Слева: 2 см, Справа: 3 см, Сверху/Снизу: 1 см |
| Абзацный отступ | 1,25 см |
| Выравнивание | По ширине |
| Интервал | Одинарный |

**Автоматическое форматирование:**
- ✅ Заголовки (ВВЕДЕНИЕ, ЗАКЛЮЧЕНИЕ и т.д.)
- ✅ Нумерованные разделы
- ✅ Таблицы с правильными границами
- ✅ Подписи рисунков
- ✅ Титульный лист

---

### 📊 3. Генератор PowerPoint

Создание презентаций Microsoft PowerPoint из текстовых конспектов.

**Поддерживаемые форматы:**
- 📝 `.txt` — обычный текст
- 📘 `.docx` — Word документы
- 📕 `.pdf` — PDF файлы

**Структура презентации:**
1. **Титульный слайд** — только тема крупно по центру
2. **Слайд с целью** — тема + первое предложение конспекта
3. **Основная часть** — текст равномерно распределён по слайдам

**Дополнительные возможности:**
- 🎨 Выбор темы оформления (светлая, тёмная, синяя, классическая)
- 🔤 Настройка шрифта и размера
- 🖼️ Добавление картинок с привязкой к слайдам
- 👁️ Предварительный просмотр

---

### 🤖 4. Чат с AcademyAI

Встроенный доступ к современным нейросетям для решения учебных задач.

**Поддерживаемые ИИ-сервисы:**

| Сервис | Особенности |
|--------|-------------|
| 🟢 **ChatGPT** (OpenAI) | Универсальный помощник |
| 🔵 **Google Gemini** | Мультимодальный ИИ от Google |
| 🟣 **Claude** (Anthropic) | Работа с длинными текстами |
| 🟠 **Perplexity AI** | Поиск информации в интернете |
| 🟡 **HuggingChat** | Полностью бесплатный, без регистрации |
| 🔴 **You.com Chat** | Поиск + генерация |

**Возможности:**
- 📷 Загрузка фотографий и изображений
- 📄 Работа с документами (PDF, Word, Excel)
- 💻 Анализ файлов с кодом
- 🌐 Открытие в внешнем браузере
